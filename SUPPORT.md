# Support

- **Documentation:** <https://purelogiccode.github.io/XISOSharp/> and the
  [wiki](https://github.com/purelogiccode/XISOSharp/wiki)
- **Questions / usage help:** open a
  [discussion or issue](https://github.com/purelogiccode/XISOSharp/issues) with
  the image format, command line, `XISOSharp -v` output and platform.
- **Bugs:** use the bug-report issue template and include a minimal reproducer
  where possible.
- **Security vulnerabilities:** do **not** open a public issue; use
  [private vulnerability reporting](https://github.com/purelogiccode/XISOSharp/security/advisories/new)
  as described in [SECURITY.md](SECURITY.md).
